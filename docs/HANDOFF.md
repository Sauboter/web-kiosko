# Web Kiosko — всё для продолжения работы

## 1. Что это
Универсальное приложение для Google Play: блокирует Android-устройство под один сайт. Аудитория — все:
магазины, кафе, клиники, ресепшены. Основа — код «Saubot Киоск» (Sauboter/saubot-kiosk-android), всё про
Saubot убрано.

## 2. Решения владельца (22.10.2026)
- Отдельный репозиторий **Sauboter/web-kiosko**, название **Web Kiosko**, пакет **kz.saubot.webkiosko**.
- Интерфейс **только на английском**.
- Бесплатно — с водяным знаком; платно — без него. Цена **$2.99 за одно устройство**, разовая покупка.
- Разовая покупка в Play привязана к аккаунту, а не к устройству → план: многократно покупаемая «лицензия на
  1 устройство» + проверка покупки и привязка к устройству на своём сервере (делать в 0.2).
- Аккаунт Google Play Developer — будет **личный** → нужен закрытый тест: ≥12 тестировщиков 14 дней подряд.

## 3. Требования Google Play (проверено 22.10.2026)
- С 31.08.2026: targetSdk **36**. Сделано: compileSdk/targetSdk 36, AGP 8.11.1, Gradle 8.13.
- Формат **AAB** — собирается в Actions вместе с APK.
- Свой ключ загрузки (upload key) в секретах GitHub: `WK_KEYSTORE_BASE64`, `WK_KEYSTORE_PASSWORD`, `WK_KEY_ALIAS`,
  `WK_KEY_PASSWORD`. Без них — тестовая подпись `keystore/test.keystore` (суффикс `-test` в имени файла).
- `USE_EXACT_ALARM` запрещён для киосков → только `SCHEDULE_EXACT_ALARM`; в меню кнопка «Allow exact alarms».
- Нужны: политика конфиденциальности, анкета Data safety, объяснение прав администратора устройства.

## 4. Особенности Android 15/16, учтённые в коде
- Edge-to-edge: в меню отступы через `setOnApplyWindowInsetsListener`.
- Predictive back: «Назад» через `OnBackInvokedCallback` (API 33+), иначе `onBackPressed`.
- Android 16 игнорирует ориентацию на планшетах → в манифесте
  `PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY=true` (временное исключение, в Android 17 уберут).

## 5. Файлы
| Файл | Что делает |
|---|---|
| `MainActivity.java` | WebView на весь экран, домены, разрешения сайта, бездействие, автообновление, водяной знак, «нет связи», ночной экран, кнопки, скрытое меню |
| `SettingsActivity.java` | Меню администратора (первый запуск = приветствие) |
| `Prefs.java` | Настройки (SharedPreferences `webkiosko`), разбор доменов, `isPro` |
| `Kiosk.java` | Владелец устройства: политики, Lock Task, HOME, автовыдача включённых разрешений |
| `Schedule.java`, `ScheduleReceiver.java`, `BootReceiver.java` | График экрана, будильники, запуск после включения |
| `KioskAdminReceiver.java` | Администратор устройства |

## 6. Версия 0.1 — что умеет
- Любой адрес; домен стартовой страницы + «Other allowed domains» (поддомены разрешены). Ограничение только для
  переходов всей страницы — встроенные фреймы (видео, карты, оплата) работают.
- http:// по галочке (иначе только https); ошибки SSL никогда не пропускаются.
- Логин/пароль сайта (HTTP Basic) — необязательно.
- Микрофон, камера, геолокация — галочками, по умолчанию выключены.
- Возврат на стартовую страницу после N минут без касаний, очистка cookies/данных, автообновление раз в N минут
  (только если минуту никто не трогал), «Назад» по страницам и масштаб — по галочке.
- Скачивания и внешние приложения заблокированы; окна `_blank` открываются в том же окне.
- Водяной знак «Web Kiosko · Free version»: не ловит касания, переезжает по углам каждые 2 мин.
  Скрывается при `Prefs.isPro` (в 0.1 всегда false).
- Из «Saubot Киоск»: скрытое меню (5 касаний + PIN), HOME, закрепление, владелец устройства, график экрана,
  громкость/яркость, блокировка кнопок, экран «нет связи».
